# Daiana Marketing Estratégico

## Descripción del Proyecto

Sitio web profesional para Daiana Paret, especialista en marketing estratégico y gestión integral de redes sociales para pymes.

## Características

- ✨ Diseño moderno y responsivo
- 🚀 Construido con React + TypeScript
- 🎨 Estilizado con Tailwind CSS
- 📱 Optimizado para móviles
- 🌟 Interfaz intuitiva y profesional

## Tecnologías Utilizadas

- **Frontend**: React 18 + TypeScript
- **Estilado**: Tailwind CSS
- **Iconos**: Lucide React
- **Build Tool**: Vite
- **Testing**: Vitest + jsdom

## Instalación y Desarrollo Local

Asegúrate de tener Node.js instalado en tu sistema.

```bash
# Clonar el repositorio
git clone [URL_DEL_REPOSITORIO]

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Construir para producción
npm run build

# Previsualizar la build de producción
npm run preview
```

## Scripts Disponibles

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run preview` - Previsualiza la build de producción
- `npm run test` - Ejecuta los tests
- `npm run lint` - Ejecuta el linter para verificar el código

## Estructura del Proyecto

```
src/
├── components/          # Componentes reutilizables
│   ├── ui/             # Componentes de UI base
│   └── landing/        # Componentes específicos del landing
├── pages/              # Páginas de la aplicación
├── hooks/              # Custom hooks
├── lib/                # Utilidades y configuraciones
└── test/               # Archivos de testing
```
